# EdJira

## Secciones

### Gestion de proyecto

- Sprint
    - Crear sprint
    - Cerrar sprint
    - Listar sprints pasados
    - Gestionar backlog
- Tareas
    - Crear tarea
        - Tipos de tarea: Epica, Historia de Usuario, Defecto
        - Resumen
        - Creador
        - Sprint actual (no obligatorio)
        - Epica (no obligatorio)
    - Visualizar tarea
    - Modificar tareas

### Gestion de testing

- Test plan
    - Crear carpetas
    - Borrar carpetas
    - Crear testSet
        - Asignar carpeta al testSet
        - Crear casos dentro de testset
- Test lab
    - Crear carpeta dentro del testSet
    - Crear testSuit dentro de la carpeta
        - Importar casos del testPlan
        - Cambiar estado de un caso en el testSuit

### Admin

- ABM Usuarios
- ABM Proyectos
